
Obsidian Backlinks
LEARN about Obsidian Backlinks ,

Backlinks ใน Obsidian คือรายการโน้ตอื่นที่ลิงก์ “เข้ามายัง” โน้ตปัจจุบัน ช่วยให้คุณเห็นบริบท ความสัมพันธ์ และจุดที่โน้ตของคุณถูกอ้างถึงจากทั่วทั้ง vault. Backlinks เป็น Core plugin และแสดงทั้งลิงก์ที่สร้างแล้วกับข้อความที่เอ่ยถึงชื่อโน้ตแต่ยังไม่ได้ลิงก์.[1]

เปิดใช้งาน Backlinks
ไปที่ Settings → Core plugins
เปิด Backlinks
เปิดโน้ตที่ต้องการตรวจสอบ
ดูแท็บ Backlinks ในแถบด้านขวา
หากไม่เห็นแท็บ Backlinks ให้เปิด Command Palette ด้วย Ctrl+P / Cmd+P แล้วรันคำสั่ง:

Backlinks: Show backlinks
Backlinks pane จะเปลี่ยนตามโน้ตที่คุณกำลังเปิดอยู่.[1]

อ่าน Backlinks
Backlinks pane มีสองส่วนหลัก:

ส่วน	ความหมาย	ตัวอย่าง
Linked mentions	โน้ตที่มี internal link ชี้มายังโน้ตปัจจุบัน	ใน Project Dashboard มี [[Obsidian Graph view]]
Unlinked mentions	โน้ตที่พิมพ์ชื่อหรือ alias ของโน้ตปัจจุบันเป็นข้อความปกติ แต่ยังไม่ได้ใส่ [[...]]	ใน Meeting Notes มีคำว่า Obsidian Graph view แต่ยังไม่เป็นลิงก์
สมมติเปิดโน้ต Obsidian Graph view:

# Project Dashboard

ใช้ [[Obsidian Graph view]] เพื่อตรวจสอบโครงสร้างของ vault
โน้ต Project Dashboard จะปรากฏภายใต้ Linked mentions ของ Obsidian Graph view.

แต่ถ้าใน Meeting Notes เขียนเพียง:

ลองใช้ Obsidian Graph view เพื่อตรวจสอบลิงก์
ข้อความนี้จะแสดงภายใต้ Unlinked mentions เพราะเป็นการเอ่ยถึงชื่อโน้ตโดยไม่ได้ลิงก์.[1]

เปลี่ยน Unlinked Mention เป็นลิงก์
เปิดโน้ตปลายทาง เช่น Obsidian Graph view
เปิด Backlinks → Unlinked mentions
เลื่อนเมาส์ไปที่ข้อความที่พบ
